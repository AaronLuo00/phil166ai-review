# PHIL 166AI 期中复习

PHIL 166AI *Artificial Agency and Society*（Harvard, Fall 2026）前半学期梳理与期中复习网页。TF 整理，非官方材料。

整个网站就是一个 `index.html`，没有构建步骤，也不依赖服务器。

## 内容

- 主张强度阶梯（可交互）：同一个机器人订票、讲「海边童年」，看各立场走到哪一级
- 课程地图：四个站点
- 概念关系图：六个分支，点格子看连接
- 按周梳理（第 1–6 周）
- 三种立场：我们在和什么说话
- 本周深读：Goldstein & Lederman、Roberts
- 作业与测验考察的能力
- 论证分类小测，以及 8 道练习题和要点
- 关键概念速查（可搜索）
- 复习 section 方案（100 / 60 分钟切换）
- 阅读与延伸链接

## 发布到 GitHub Pages

1. 把 `index.html`、`README.md`、`.nojekyll` 放到仓库根目录，推到 `main`。
2. 在仓库的 Settings → Pages 里，Source 选 “Deploy from a branch”，Branch 选 `main`，目录选 `/ (root)`。
3. 一两分钟后，网站会出现在 `https://<用户名>.github.io/<仓库名>/`。
